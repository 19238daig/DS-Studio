# DS Studio 问答工作台设计

本次设计使用已安装的 frontend-design 与 UI/UX Pro Max。产品是本机数据分析工作台，主任务是连接数据、提问、跟踪分析并下载可追溯的报告。

## 设计令牌

| 角色 | 值 | 用途 |
|---|---|---|
| 墨色 | `#18343C` | 正文、标题 |
| 工作台底色 | `#F2F6F5` | 主区画布 |
| 纸面 | `#FFFFFF` | 对话与成果 |
| 深色导航 | `#153139` | 会话和数据连接 |
| 主操作 | `#087F73` | 发送、选中、焦点 |
| 次级文字 | `#526B72` | 说明与状态 |

字体使用系统 `Segoe UI / Microsoft YaHei / PingFang SC`，不依赖外网字体。正文保持 14–16px，辅助文字至少 12px，数字使用等宽数字特性，完整显示而不省略。

## 布局

桌面以安静的导航栏承载数据连接；主区左对齐，以对话作为最主要内容；任务侧栏以完整数值和清晰状态辅助阅读。空态用真实任务入口，不展示虚构指标。

```text
会话 / 数据连接 | 工作空间标题与服务状态
                | 对话 / 数据 / 报告 / 日志 / 记忆
                | 对话与输入区域          | 数据来源
                |                        | 任务状态与完整用量
```

手机沿用原生可收起侧栏。主内容单列，侧栏任务信息随内容滚动；标签栏可局部横向滚动，表格和代码在自身区域滚动，页面不得横向溢出。保持可见焦点和减少动画偏好。

## 检索取舍

Pro Max 对 analytics dashboard 的设计系统检索和一次收窄重试均返回了适合本产品的 Data-Dense Dashboard 风格，但返回的 Enterprise Gateway/Contact Sales 营销布局不适合分析工作台，因此没有采用或冒称其为匹配建议。采用其可读性、信息密度和可达性检查；保留项目既有青绿识别。远程 Fira 字体和 GSAP 推荐未采用，避免新增网络依赖和不必要动画。

针对 numeric labels overflow 的结果中采用 Overflow Hidden 与 Table Handling 的规则；针对 keyboard focus visibility 采用 Focus States 与 Focus Not Obscured。Streamlit 不在上游 stack 列表中，因此未伪装为 React/Tailwind，使用栈无关规则与现有原生控件。

## 自查与落地

旧版的极小灰字、重复卡片和截断指标降低了可读性。本次重点为清晰文字、会话导航、主操作输入区、任务进度和完整 Token/耗时；不增加装饰图表、全屏背景图片或悬浮挡板。数据、权限、上传上限和任务操作保持原行为。
